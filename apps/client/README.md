# EagleChat client


P2P message client


## Environment Variables

### Default ID Manager

These are optional

- **ID_MANAGER_IP**
- **ID_MANAGER_PORT**
- **ID_MANAGER_PUBLIC_KEY_FILE**

The ip and port will be used in `http://<ip>:<port>` requests, it needs to be a valid ip, either ipv4 or ipv6.

The public key file needs to store a simplecrypto-generated public key in bytes.
